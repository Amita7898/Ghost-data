# Provenance and licensing

Ghost Data is a personal data-deletion investigation platform inspired by an auditing
challenge. The owner confirmed the necessary rights to reuse and publish their
original code and selected the [MIT license](../LICENSE). This is not independent
legal clearance or a license to redistribute third-party challenge materials.

Original competition data, answers, problem text, organizer internals, submission
archives and private development conversations are excluded. Fictional benchmark
worlds, examples, prompts, source and UI were authored for this standalone project.
Its `evaluator_only` fixtures are independent synthetic reference data, not challenge
answers. Runtime tools never receive those files or labels.

Dependencies retain their upstream licenses and are installed, not vendored. Review
third-party notices before redistributing built packages. Ollama binaries and model
weights are not included; verify the selected runtime/model's own terms before any
redistribution. A mutable model tag is not a license or reproducibility guarantee.

Historical reviews and benchmark prototypes remain in the unchanged `v0.4.0` Git
history, not the main documentation navigation. See [evaluation](evaluation.md) for
recovery commands and why no Git history rewrite was performed.
