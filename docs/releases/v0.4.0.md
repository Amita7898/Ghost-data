# Ghost Data v0.4.0 — local AI investigation console

Initial public portfolio release. Licensed under MIT; model/runtime binaries and
competition assets are not distributed.

Ghost Data is a locally runnable AI-assisted data deletion investigation console.
Its React/TypeScript workspace connects to FastAPI, SQLite and a genuine bounded
Ollama tool-calling agent, with independently validated evidence conclusions.

## Included

- Dashboard, case creation, three-panel workspace, evidence explorer and run history.
- Schema-validated JSON evidence uploads, exact source references and SHA-256 provenance.
- Six typed read-only tools, model-proposed hypotheses, deterministic acceptance/
  rejection and independent proof checks; model summaries are not audit authority.
- Persistent SSE events, reload/reconnect, idempotent starts, serialized inference,
  cancellation and clear failed/interrupted execution states.
- Three genuine synthetic offline recordings, including accepted hypotheses and
  rejected conflicting-state proposals; no model or API key required for replay.
- Reproducible synthetic worlds/benchmarks, documented source contracts and limitations.
- Setup diagnostics, security tests, browser accessibility checks, real demo media
  and configured Python/frontend/offline-browser GitHub Actions.

## Measured scope

The final review reruns the actual application and tests; see the prepublication
review for newly executed results versus historical benchmark measurements. Historic
four-case diagnostics scored 25% deterministic, 75% extraction and 75% agent; the
agent was slower and had complementary errors. Structured synthetic regressions
are not production correctness claims. CI results are available in the repository Actions tab.

## Boundaries

Localhost/single-user only. No compliance certification, destructive operations,
cloud fallback, general PDF/OCR ingestion or live database connectors. Source
authenticity and declared inventory scope remain assumptions. Live local inference
can exceed two minutes. The remaining moderate development type-generator chain is
explicitly documented; do not use it for untrusted schemas. Model/runtime weights,
private evidence and competition materials are not distributed.
